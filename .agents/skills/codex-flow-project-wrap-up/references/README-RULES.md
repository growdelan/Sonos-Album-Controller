# Zasady README

README jest dla człowieka, który chce uruchomić lub zrozumieć projekt.

Aktualizuj README, gdy zmienił się:
- sposób uruchamiania
- wymagania systemowe
- komendy developerskie
- konfiguracja środowiska
- wymagane zmienne środowiskowe
- opis najważniejszego zachowania aplikacji
- ograniczenia istotne dla użytkownika lub developera

Nie aktualizuj README, gdy:
- zmieniły się tylko wewnętrzne detale implementacji
- poprawka była kosmetyczna
- informacja należy do `STATUS.md`, `ROADMAP.md` albo `spec.md`
- chodzi tylko o metrykę harnessu, walidację lub handoff — to zapisuj w `STATUS.md`
