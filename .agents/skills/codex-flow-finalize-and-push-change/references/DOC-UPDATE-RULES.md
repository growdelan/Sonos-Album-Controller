# Zasady aktualizacji dokumentacji

## ROADMAP.md

Aktualizuj statusy milestone'ów zgodnie z faktycznym postępem. Nie oznaczaj `done`, jeśli review ma problem krytyczny albo walidacja blokuje zmianę.

## STATUS.md

Zapisz aktualny stan projektu:
- aktywny milestone lub batch
- wynik walidacji
- wynik review
- istotne błędy narzędzi i ich kategorie
- obserwacje keep rate
- ograniczenia i ryzyka
- najbliższy sensowny następny krok
- handoff, jeśli sesja nie jest domknięta

## spec.md

Aktualizuj tylko wtedy, gdy wykonana praca zmieniła lub doprecyzowała decyzje techniczne albo zachowanie systemu.

## README.md

Aktualizuj tylko wtedy, gdy zmienił się:
- sposób uruchamiania
- wymagania
- komendy developerskie
- opis zachowania funkcji
- ważne ograniczenia lub istotne zachowania systemu

Nie aktualizuj README kosmetycznie.
