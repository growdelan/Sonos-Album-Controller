# Handoff template

Użyj przy przejściu między sesjami, modelami albo agentami. Handoff ma być krótki, wykonawczy i wolny od szumu.

```text
## Handoff

Powód handoffu:
- koniec sesji / zmiana wariantu modelu / zmiana roli / blokada / inny:

Źródło:
- agent:
- model/profil:
- format edycji:

Cel:
- agent:
- model/profil:
- format edycji:

Aktualny milestone / batch:

Stan pracy:
- zrobione:
- w trakcie:
- niezrobione:

Zmienione pliki:
- 

Decyzje techniczne, których nie wolno zgubić:
- 

Walidacje:
- komenda / sposób:
- wynik:

Review:
- wynik:
- problemy krytyczne:
- problemy ważne:

Błędy narzędzi:
- kategoria:
- objaw:
- działanie naprawcze:

Założenia lub formy pracy z poprzedniego kontekstu, których nowy kontekst nie powinien zakładać:
- 

Następny bezpieczny krok:

Czego nie robić:
- 
```

## Reguły

- Nie wklejaj pełnych logów, jeśli wystarczy streszczenie.
- Oddziel fakty od domysłów.
- Nie ukrywaj nieudanych walidacji.
- Przy zmianie wariantu modelu przypomnij nowemu kontekstowi, że historia poprzedniego przebiegu może zawierać założenia wymagające sprawdzenia.
