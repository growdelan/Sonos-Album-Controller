# Sprint contract template

Użyj przed implementacją milestone’u albo batcha. Kontrakt może być zapisany w odpowiedzi agenta, w `STATUS.md` albo w osobnym roboczym pliku, jeśli praca jest długa.

```text
## Kontrakt sprintu

Milestone / batch:

Profil modelu:
- aktywny model/profil:
- format edycji:
- model switch w tym sprincie: nie

Cel:

Zakres:
- 

Poza zakresem:
- 

Definition of Done:
- 

Pliki/kontekst do przeczytania przed kodem:
- AGENTS.md
- STATUS.md
- ROADMAP.md: <fragment>
- spec.md: <sekcje>
- <konkretne pliki kodu/testów>

Plan implementacji:
1. 
2. 
3. 

Walidacja:
- komenda / sposób:
- oczekiwany wynik:

Ryzyka:
- 

Stop conditions:
- niejasne wymaganie wymagające decyzji człowieka
- konieczność wyjścia poza zakres
- nieprzechodzące testy, których naprawa wymaga nowego zakresu
- potrzeba przełączenia wariantu modelu bez handoffu
- UnknownHarnessBug

Handoff po zakończeniu:
- zmienione pliki:
- walidacje:
- problemy do review:
```
